# Протокол личного распада

```
В третьем подъезде до сих пор горит одно окно —
там кто-то считает свои дни и сбивается на четвёртом.

Бот считает тоже. Молча и без жалости.
```

Бот, который разговаривает с тобой так, будто ты не пользователь,
а объект наблюдения. Он не мотивирует и не утешает — снимает показания
и говорит, что видит.

Одно запрещено протоколом: превращать твоё состояние в **постоянное**.
Всё обратимо, пока измеряется.

---

## Команды

| | |
| --- | --- |
| `/start` | Ветка заведена. Первая запись пустая. |
| `/pulse` | Краш-тест дня: три вопроса, один вывод. |
| `/fork` | Развилка. Две ветки, цена каждой. |
| `/seal` | Запечатать: привычку, отношения, версию себя. |
| `/audit` | Недельный аудит по журналу. |
| `/voice` | Сменить голос. |
| `/wipe` | Стереть всё. Второй раз не спросит. |

Остальное время — просто разговор.

## Голос

Характер живёт не в коде.

- `docs/LAWS.md` — законы, общие для всех голосов
- `bot/personas/*.yaml` — промпт, образцы речи, запрещённые обороты, длина

Хочешь другой характер — не трогай Python, напиши новый YAML.
`app/style.py` после генерации вычищает всё, что законы запрещают.

## Стек

Python 3.12 · aiogram 3 · Postgres на сервере, SQLite локально · Anthropic API.
Long polling, поэтому ни домена, ни белого IP не нужно.

## Запуск

```bash
cp .env.example .env      # токен бота и ключ модели
pip install -e "./bot[dev]"
python -m app.doctor      # проверка окружения
python -m app.main
```
