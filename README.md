# Протокол личного распада

```
Панельки стоят как зубы в челюсти, которую давно не чистили.
Провода провисли. Собака знает расписание лучше жильцов.
В третьем подъезде до сих пор горит одно окно —
там кто-то считает свои дни и сбивается на четвёртом.

Бот считает тоже. Молча и без жалости.
```

Телеграм-бот, который разговаривает с тобой так, будто ты не пользователь,
а объект наблюдения. Он не мотивирует и не утешает — снимает показания
и говорит, что видит.

Одно запрещено протоколом: превращать твоё состояние в **постоянное**.
Всё обратимо, пока измеряется.

**[Бот в Telegram](https://t.me/spravka_o_raspade_bot)**

## Команды

| | |
| --- | --- |
| `/start` | Ветка заведена. Первая запись пустая. |
| `/note` | Записать в журнал: `/note не спал третью ночь` |
| `/journal` | Лента журнала: заметки и ритуалы по времени |
| `/find` | Искать по журналу и по всей переписке: `/find ночь` |
| `/spravka` | Справка за неделю картинкой, с печатью |
| `/pulse` | Краш-тест дня: три вопроса, один вывод |
| `/fork` | Развилка. Две ветки, цена каждой |
| `/seal` | Запечатать: привычку, отношения, версию себя |
| `/audit` | Недельный аудит по журналу |
| `/voice` | Сменить голос |
| `/wipe` | Стереть всё. Второй раз не спросит |

Остальное время — просто разговор. Можно прислать фотографию:
бот посмотрит и зацепится за одну деталь. Голос он не слышит.

## Журнал

Всё, что сказано обеими сторонами, ложится в журнал одного человека.
Никто другой его не видит. Записи копятся сами, специально ничего вести
не надо — `/note` только для того, что хочется отметить отдельно.

Чем длиннее журнал, тем точнее бот замечает, что возвращается.

## Справка

`/spravka` рисует бланк: период наблюдения, сколько реплик снято, сколько
записей, **сколько обращений было ночью**, какой голос преобладал, цитата
из последнего ответа и косой сургучный штамп.

Это не нейросеть, а код на Pillow — стоит ноль и рисуется за долю секунды.

## Голос

Характер живёт не в коде.

- `docs/LAWS.md` — законы, общие для всех голосов
- `bot/personas/*.yaml` — промпт, образцы речи, запрещённые обороты, длина

Хочешь другой характер — не трогай Python, напиши новый YAML.
`app/style.py` после генерации вычищает всё, что законы запрещают.

## Стек

Python 3.12 · aiogram 3 · Postgres на сервере, SQLite локально ·
Anthropic API · Pillow для справки.
Long polling, поэтому ни домена, ни белого IP не нужно.

## Запуск

```bash
cp .env.example .env      # токен бота и ключ модели
pip install -e "./bot[dev]"
python -m app.doctor      # проверка окружения
python -m app.main
```
